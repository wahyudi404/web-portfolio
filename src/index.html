Tentang Diri Saya

Halo, Saya Wahyudi Seorang Web Developer

Saya adalah seorang web developer yang memiliki pengalaman dalam mengembangkan aplikasi web menggunakan berbagai bahasa pemrograman dan framework. Saya juga aktif terlibat dalam proyek-proyek kelompok yang membantu saya untuk memperkuat kemampuan saya dalam bekerja secara kolaboratif, mengatasi tantangan teknis, dan mengelola waktu secara efektif.

Saya memiliki kemampuan dalam mengembangkan aplikasi web menggunakan berbagai bahasa pemrograman dan framework, seperti HTML, CSS, JavaScript, React, Node.js, dll. Saya juga memiliki pengalaman dalam menggunakan database seperti MySQL, PostgreSQL, Oracle. Selain itu, saya juga memiliki kemampuan dalam menggunakan alat pengembangan seperti Visual Studio Code, Git, Docker, dll.
